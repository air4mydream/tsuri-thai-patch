ข้อจำกัด
0037:00 เป็นสูตร RAM/Raw ของ NES ใช้ CPU Address 0x0037, Value 0x00 และไม่มี Compare
Mesen ใช้การแทนค่าที่อ่าน ขณะที่ FCEUX RAM patch เขียนค่าเป็นรอบ
การใช้ Address/Value เดียวกันจึงไม่ได้รับรองผลเหมือนกันทุกจังหวะ
ไฟล์ .cht ของ FCEUX, RetroArch และ DuckStation ไม่ใช่รูปแบบเดียวกันทั้งหมด
ยังไม่มีไฟล์หรือผลทดสอบสำหรับอีมูอื่นในชุดนี้
NES Game Genie ใช้ที่อยู่ PRG ช่วง $8000-$FFFF จึงแปลง $0037 เป็น Game Genie ตรงๆ ไม่ได้
หากต้องการ Game Genie ต้องวิเคราะห์คำสั่งเกมและสร้างสูตรอีกชุด
