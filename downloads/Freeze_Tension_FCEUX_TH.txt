วิธี Import และเปิดใช้สูตรใน FCEUX

   ต้องเป็นไฟล์ .cht ไม่ใช่ .cht.txt
2. เปิดเกมภาค Blue Marlin Hen สำหรับ Famicom ใน FCEUX
3. เลือกเมนู Tools → Cheats
4. กด Import...
5. เลือกไฟล์ BlueMarlin_FreezeTension_FCEUX.cht แล้วกด Open / เปิด
6. จะเห็นรายการ Freeze Tension (John Lowery) ในรายการสูตร
7. ติ๊กเครื่องหมายถูกหน้ารายการเพื่อเปิดใช้
   ไฟล์ที่แจกเริ่มต้นปิดสูตรไว้ การ Import อย่างเดียวยังไม่ได้เปิดสูตร
8. ปิดหน้าต่าง Cheats แล้วกลับไปเล่นเกม

วิธีปิดสูตร
กลับไปที่ Tools → Cheats แล้วเอาเครื่องหมายถูกหน้ารายการ Freeze Tension ออก
ไม่ต้องลบรายการสูตร หากต้องการกลับมาเปิดใช้ใหม่ในภายหลัง

หากไม่เห็นสูตร
- ตรวจว่าเปิดเกมอยู่ก่อน Import
- ตรวจว่าเลือกไฟล์ .cht สำหรับ FCEUX จากหน้านี้ ไม่ใช่ไฟล์สูตร DuckStation ของเกม PS1

- ตรวจ Address: 0037 และ Value: 00 ไม่ต้องใส่ Compare
- ตรวจว่าเล่นเกมภาค Blue Marlin Hen ของ Famicom
