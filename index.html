วิธีใส่สูตรใน Mesen / MesenCE
  1. เปิดเกม แล้วเลือกเมนู Tools → Cheats จากนั้นกด Add
  2. ช่อง Description: ใส่ Freeze Tension
  3. ช่อง Cheat Enabled: ติ๊กเครื่องหมายถูก
  4. ส่วน Codes → Format: เลือก Custom (AAAA:VV:CC)
  5. ช่อง Codes: วางสูตร 0037:00 โดยไม่ต้องเติมค่า Compare
  6. กด OK เพื่อเพิ่มสูตรและกลับไปหน้ารวม Cheats
  7. ตรวจว่ารายการ Freeze Tension มีเครื่องหมายถูก และเอาเครื่องหมายถูกออกจาก Disable all cheats
  8. กด OK เพื่อกลับเข้าเกม สูตรจะทำงานขณะเล่น

วิธีปิดสูตร: กลับไปที่ Tools → Cheats เอาเครื่องหมายถูกหน้ารายการ Freeze Tension ออก แล้วกด OK

ใช้กับอีมูอื่นได้ไหม?

อีมูอื่นต้องรองรับสูตร RAM/Raw ของ NES จึงจะนำค่า Address 0037 และ Value 00 ไปทดลองได้ ไฟล์ .cht ของแต่ละอีมูใช้แทนกันไม่ได้เสมอ

สูตรนี้แปลงเป็นรหัส NES Game Genie โดยตรงไม่ได้ หากอีมูรับเฉพาะ Game Genie ต้องวิเคราะห์โค้ดเกมเพื่อสร้างสูตรอีกแบบ

ต้องใช้ไฟล์เกมแบบไหน?

ใช้ Tsurikichi Sanpei: Blue Marlin Hen ภาษาญี่ปุ่นสำหรับ Famicom แบบ .nes ที่ตรงกับแพตช์เดิม ขนาด 131,088 ไบต์ รวมส่วนหัว iNES หากเก็บเป็น ZIP ให้แตกไฟล์ก่อนเลือก

ขึ้นว่า ROM ไม่ตรง ต้องทำอย่างไร?

เลือกต้นฉบับญี่ปุ่นที่ยังไม่แปะแพตช์และเป็นรุ่นที่รองรับ ชื่อไฟล์เปลี่ยนได้ แต่ข้อมูลต้องตรง หากเป็นรอมต่างรุ่นหรือส่วนหัวต่างกัน ระบบจะไม่ยอมแปะแพตช์

แปะแพตช์เสร็จแล้วเล่นอย่างไร?

เบราว์เซอร์จะบันทึกไฟล์ .nes ฉบับภาษาไทย นำไฟล์ที่ได้ไปเปิดใน Mesen หรืออีมู Famicom ที่คุณใช้ หากเบราว์เซอร์ถามสิทธิ์ดาวน์โหลด ให้กดยอมรับ

ต้องเปิดสูตรก่อนแปะแพตช์ไหม?

ไม่ต้องเปิดสูตรตอนแปะแพตช์ สูตรเปิดและปิดในอีมูขณะเล่นได้ ส่วน ROM ภาษาไทยใช้งานได้ตามปกติโดยไม่เปิดสูตร

สูตรเปิดแล้วแต่ไม่ทำงาน?

Mesen / MesenCE: ตรวจว่าเลือก Custom และกรอก 0037:00 ติ๊ก Cheat Enabled และเอาเครื่องหมายถูกออกจาก Disable all cheats

FCEUX: หลัง Import ต้องติ๊กเครื่องหมายถูกหน้ารายการ Freeze Tension ด้วย เพราะไฟล์เริ่มต้นปิดสูตรไว้ ตรวจ Address 0037 และ Value 00 สูตรใช้กับเกม Famicom ภาคนี้เท่านั้น
